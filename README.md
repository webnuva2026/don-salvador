# Don Salvador — Pizzas y Carnes

Sitio web de la pizzería Don Salvador (Monsefú). React + Vite + TypeScript.

- Contacto y redes: `src/config/contact.ts`
- Carta y precios: `src/data/menu.ts`
- Imágenes: `public/img/`

```bash
npm install
npm run dev     # desarrollo en http://localhost:3001
npm run build   # producción
```
